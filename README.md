# Stieve Software Company — Foundation

Este repositório contém a documentação fundamental da Stieve Software Company.

A SSC será uma plataforma de engenharia de software orientada por inteligência artificial, capaz de planejar, desenvolver, testar, documentar, publicar e evoluir múltiplos projetos.

## Princípio central

> Arquitetura primeiro. Automação sempre.
